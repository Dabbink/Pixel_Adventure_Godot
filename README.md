# Pixel_Adventure_Godot
I made a 2D game with my team members.
I did made this game for a school project in Godot.
# To install the 2D Pixel Adventure game, you need to download Godot from this website: https://godotengine.org/download/windows/
First, You need to install it, because I don't know how to make the .exe yet. To be able to play this 2D Game of Pixel Adventure, you need to install Godot from the URL above. You need to download it. After that, you need to open GitHub and download the game on the link: https://github.com/Dabbink/Pixel_Adventure_Godot.
Secondly, you need to press the green code button.
The next step is to click the Download ZIP button.
Next, you need to click the import button on Godot.
After, You need to click the recently installed file.
After that, You need to click select this map.
then, open the game.
And finally, you need to click the play button on the top right.
